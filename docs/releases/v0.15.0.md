Categories become tabs above the inbox, and Cleanup lets you choose what it
touches instead of all or nothing.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Categories moved out of the sidebar into tabs above the message list: All,
  Important, Transactions, Newsletters, Other and Spam. In the sidebar they
  looked exactly like folders, so it was not clear they filtered the inbox.
- Every Cleanup suggestion that covers several senders has a Choose button.
  It lists the senders with a checkbox each, so you can empty the spam of
  two senders out of six. The main button still does everything in one click.
- Unsubscribing works the same way: untick the lists you want to keep. Lull
  Mail remembers them and stops suggesting them; a link at the bottom of the
  page brings them back.
- Long lists in those dialogs show how many are ticked, offer select all and
  clear all, and can be filtered by typing a name.
- When an unsubscribe partly fails, the message names only the lists that
  refused.
- Smaller fixes: Open the Trash from Cleanup now opens the trash, the
  read/unread button is right as soon as a message opens, deleting a label,
  folder or draft asks in the app's own dialog, and sidebar sections open
  and close from the keyboard.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.0.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.0.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.0.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Nothing to migrate. The tab you pick stays selected while you visit other
  folders.
- Running from source: the optional MCP server needs the `mcp` package below
  2.0, which removed the API it uses. `requirements.txt` now says so.
