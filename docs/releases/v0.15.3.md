A fix release: two kinds of crafted message can no longer freeze the image
blocker, a few rough edges of 0.15.2's image blocking are smoothed out, and
dates in the list follow the clock.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Two kinds of crafted message could freeze the image blocker in the reading
  pane and the assistant's reader for seconds to minutes: a long run of
  spaces in a style's url(, and a long run of commas in an image's srcset.
  Those two now open at once. Other crafted shapes still could; 0.15.4
  closes them.
- With images blocked, SVG graphics in messages that set a remote base
  address (gradients, clip paths, filters) display correctly again, with no
  banner when nothing remote is there.
- Messages whose pictures are referenced from an embedded stylesheet's url(),
  or with relative paths behind an unusual base address, now show the
  "images blocked" banner, so you can load them.
- With "Load for this email" and trusted senders, messages using web fonts
  no longer lose a blank line in preformatted text. A message with a link
  flagged as suspicious still could, until 0.15.4.
- On macOS and Linux, a trusted sender's message could make a background
  request through a preload link. The plain form of that link is now
  removed; variations of it still got through until 0.15.4.
- "Aujourd'hui" and "Hier" in the message list now change on their own at
  midnight, and catch up as soon as the window comes back after the
  computer slept. Before, an app left open overnight kept calling
  yesterday's mail today's until the list was reloaded.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.3.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.3.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.3.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.
