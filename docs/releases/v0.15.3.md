A privacy and reliability release: with images blocked, an open message no
longer loads anything from the internet, and dates in the list follow the
clock.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Blocking remote images now blocks every remote resource in the message,
  not only ordinary pictures. Backgrounds set in the message's styles or on
  tables, web fonts, video posters, SVG pictures and a few rarer forms still
  loaded before, and any one of them can tell a sender you opened the
  message. The side reader that opens messages cited by the assistant is
  covered too.
- "Load for this email" and trusted senders bring back the sender's
  pictures, styles, fonts and media. Embedded frames and objects stay off.
- The "images blocked" banner now appears for every message that has
  something to load, including newsletters that point to their pictures
  with relative paths or keep them in an embedded stylesheet.
- Messages crafted to freeze the reading pane or the assistant's reader
  open at once.
- "Aujourd'hui" and "Hier" in the message list now change on their own at
  midnight, and catch up as soon as the window comes back after the
  computer slept. Before, an app left open overnight kept calling
  yesterday's mail today's until the list was reloaded.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.3.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.3.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.3.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.
