A fix release for 0.15.2's image blocking, and list dates that follow the clock.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- A long run of spaces in a style's url(, or of commas in a srcset, no longer
  freezes the reader. Other crafted shapes still could, until 0.15.4.
- With images blocked, SVG graphics under a remote base address (gradients,
  clip paths, filters) display again, and raise no banner by themselves.
- Pictures referenced from an embedded stylesheet, or by relative paths behind
  an unusual base address, now show the "images blocked" banner.
- Loaded messages with web fonts keep the blank lines of their preformatted
  text, except next to a flagged link (fixed in 0.15.4).
- On macOS and Linux, a trusted sender's preload link could make a request.
  Plain ones are now removed; others still got through until 0.15.4.
- On every platform, a trusted sender's prefetch links in unusual markup, and
  its inline frames, also got through until 0.15.4.
- "Aujourd'hui" and "Hier" in the list now move at midnight, and catch up
  after the computer sleeps, with no need to reload the list.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.3.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.3.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.3.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Nothing to migrate. Senders you already trusted for images stay trusted.
