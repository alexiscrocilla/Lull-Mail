A fix release: crafted messages can no longer freeze the reading pane, a few
rough edges of 0.15.2's image blocking are smoothed out, and dates in the
list follow the clock.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Two kinds of crafted message could freeze the reading pane or the
  assistant's reader for seconds to minutes. They now open at once.
- With images blocked, SVG graphics in messages that set a remote base
  address (gradients, clip paths, filters) display correctly again, with no
  banner when nothing remote is there.
- Messages whose pictures come from an embedded stylesheet, or sit behind an
  unusual base address, now show the "images blocked" banner, so you can
  load them.
- With "Load for this email" and trusted senders, the text is shown exactly
  as sent: messages using web fonts could lose a blank line in preformatted
  text.
- On macOS and Linux, a message from a trusted sender could still make one
  kind of background request; it no longer does.
- "Aujourd'hui" and "Hier" in the message list now change on their own at
  midnight, and catch up as soon as the window comes back after the
  computer slept. Before, an app left open overnight kept calling
  yesterday's mail today's until the list was reloaded.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.3.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.3.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.3.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Nothing to migrate. Senders you already trusted for images stay trusted.
