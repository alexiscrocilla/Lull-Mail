Attachments: Download now saves the file, and a new eye button previews it
without leaving the app.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- On macOS, Download used to open the file inside Lull Mail — a PDF took
  over the window and there was no way back to the inbox short of quitting.
  It now saves the file, like it already did on Windows.
- Download puts the file in your Downloads folder and tells you so, with a
  Show button that opens the folder with the file selected. Saving the same
  file twice keeps both copies.
- An eye button next to Download opens a preview inside the app: PDFs,
  images and text files. Close it with Escape or the cross, and you are
  back on your email.
- The eye only appears on files that can safely be shown. Anything the
  scanner flagged still has to be downloaded, after the same warning as
  before.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.14.0.exe` | Double-click |
| macOS 12+ | `LullMail-0.14.0.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.14.0.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Nothing to migrate. Files already saved stay where they are.
- Third-party libraries were updated, including the one that handles
  encryption of your stored credentials.
