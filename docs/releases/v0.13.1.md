A fix release: in 0.13.0 background sorting stopped a few minutes after
launch, and the inbox said it was downloading messages for ever.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Sorting no longer stops. A few minutes after launch the inbox settled on
  "Downloading messages…" and stayed there — and behind it, downloading
  message bodies and sorting them had stopped for good. Mail still arrived;
  none of it was triaged. Restarting the app was the only way out, until
  it happened again.
- Actions taken while a mailbox is unreachable — marking read, starring,
  deleting — now wait for it to come back instead of being retried against
  a server that is down, which could occupy the app for twenty minutes at
  a stretch.
- After a dropped connection the window no longer comes back showing the
  state it was in before the drop.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.13.1.exe` | Double-click |
| macOS 12+ | `LullMail-0.13.1.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.13.1.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Only 0.13.0 is affected. Nothing was lost: mail that went unsorted is
  picked up on the next pass after updating.
