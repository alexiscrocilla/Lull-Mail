Search and Cleanup are the two pages this release rewrites, and multi-account
use is correct across the app for the first time.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- Search filters are controls you click. Sender, subject, date range,
  attachments and starred each have a field or a checkbox, instead of a help
  card listing eleven operators to retype. Typed operators still work.
- Every filter that is on now says so, as a chip you can remove on its own.
  An operator in the search box, an account picked in the sidebar or a label
  no longer filter your inbox invisibly.
- Cleanup shows you the list before it empties anything. Past a few hundred
  messages the button opens the senders it is about to touch, with counts,
  and you untick the ones to keep.
- Cleanup is per mailbox. It has an account picker again, and unsubscribing
  treats the same newsletter in two accounts as two subscriptions, because
  the link only ever cancels one of them.
- Mail rows show which account they arrived in, and the sidebar counters
  follow the account filter instead of summing every mailbox.
- New mail lands in about two seconds instead of on a timer, and an idle
  window no longer polls in the background.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.10.0.exe` | Double-click |
| macOS 12+ | `LullMail-0.10.0.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.10.0.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Updates are signed from this release on. The app checks an Ed25519
  signature over the release manifest before it offers you anything, and
  refuses an update it cannot verify.
- If the AI is switched off for an account, the app now honours that
  everywhere, including the draft button in the reading pane.
- First launch after upgrading rebuilds one database index and refreshes
  query statistics. On a large mailbox that adds a moment to startup, once.
