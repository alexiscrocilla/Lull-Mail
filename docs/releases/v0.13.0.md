Mail now arrives on its own, Cleanup shows you what it will delete, and
search filters are controls you click.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- New mail appears in the list as it arrives, in about two seconds, instead
  of when a timer next fires. A window you are not using no longer polls in
  the background at all.
- Cleanup shows the list before it empties anything. Past a few hundred
  messages the button opens the senders it is about to touch, with counts,
  and you untick the ones to keep.
- Cleanup itself is a ranked list of at most three things worth doing,
  rather than three tabs and twenty controls nobody used.
- Search filters are controls you click — sender, subject, date range,
  attachments, starred — instead of a help card listing eleven operators to
  retype. Typed operators still work, and every filter that is on is now a
  chip you can remove on its own.
- The app shows less: a mail row that answers four questions, a reading pane
  with six controls, settings behind one disclosure, and setup in three
  screens.
- Several mailboxes now behave like several mailboxes. Rows say which
  account they arrived in, the sidebar counters follow the account filter,
  and Cleanup is scoped per mailbox — unsubscribing treats the same
  newsletter in two accounts as the two separate subscriptions it is.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.13.0.exe` | Double-click |
| macOS 12+ | `LullMail-0.13.0.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.13.0.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Updates are signed from this release on. The app verifies an Ed25519
  signature over the release manifest before offering you anything, and
  refuses an update it cannot verify.
- If the AI is switched off for an account, that is now honoured everywhere,
  including the draft button in the reading pane.
- Pillow, requests, python-multipart and pytest are upgraded to their
  patched versions.
- First launch after upgrading rebuilds one database index and refreshes
  query statistics. On a large mailbox that adds a moment to startup, once.
