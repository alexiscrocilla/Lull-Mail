A maintenance release: the image library bundled with the app moves to a
version that fixes a long list of security advisories.

Lull Mail: local-first IMAP desktop client (triage, reply, compose, labels, filing).

## Highlights

- The image library (Pillow) is updated from 12.3.0 to 13.0.0, which fixes
  several critical and high-severity advisories. Lull Mail only uses it to
  draw its own tray icon, never to open images from your mail, but the
  installers no longer carry the affected version.
- The bundled copy of DOMPurify is updated to 3.4.16.

## Install

| Platform | File | Install |
|----------|------|---------|
| Windows 10/11 | `LullMail-Setup-0.15.1.exe` | Double-click |
| macOS 12+ | `LullMail-0.15.1.dmg` | Open, drag to Applications |
| Linux | `LullMail-0.15.1.tar.gz` | Extract and run `LullMail/LullMail` |

- **Windows**: SmartScreen (unsigned installer). *More info* → *Run anyway*.
- **macOS**: Gatekeeper (app not notarized). Right-click the app → *Open*.

## Notes

- Nothing changes in the app itself, and nothing to migrate.
- Running from source now needs Python 3.11 or later.
